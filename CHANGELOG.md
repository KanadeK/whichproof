# Changelog

All notable user-visible changes are documented here.

## [0.1.0] - 2026-08-30

### Added

- Ordered PATH/PATHEXT executable candidate capture without candidate execution.
- Strict `whichproof.snapshot.v1` JSON evidence with byte hashes and atomic writes.
- Live `verify` and offline `diff` commands with deterministic text/JSON reports.
- Seven explicit drift rules, stable exit codes, a synthetic shadowing demo, cross-platform CI,
  and release-equivalent packaging checks.
